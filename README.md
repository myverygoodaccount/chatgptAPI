# chatgptAPI
An api that let's you use chatGPT through terminal or as a Python class.

# Info
It uses playwright to launch a chromium browser, which goes to chatgpt.com and automatically interacts with the website to get responses from chatgpt.
It currently only uses the free tier with no account, but in the future I might add the ability to use your accounts.
It also DOES NOT SUPPORT headless for now. (cloudflare)

# Important
Expect bugs and remember that this is only a project that I made and do not rely on it to work nor should you use it at large scale.

# Usage
1. download all dependencies and this folder.
2. install playwright and (playwright's chrome or chrome).
3. run ChatgptAPI.py or read it and use the api.
